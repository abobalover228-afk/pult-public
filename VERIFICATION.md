# Проверка версии 1.1.0

- Собраны личные приложения Пульт / Лимиты и отдельные публичные приложения для macOS arm64.
- Публичные приложения собраны с deployment target macOS 14.0; локальные — текущим SDK установленного компьютера.
- Пройдены офлайн-проверки API-настроек и отправки через URLProtocol / транспорт-заглушку, без внешних запросов и настоящих ключей.
- Проверены metadata CRUD, сохранение старого ключа при редактировании, ошибки Keychain-заглушки, отсутствие ключа в JSON и теле запроса, редактирование URL, защита от перенаправлений, сообщения HTTP 401/403/404/429/5xx и неправильный ответ.
- Проверены реальная ветка API-диспетчеризации Chat, контекст диалога, очередь, отмена, игнорирование позднего ответа, сохранение текста при ошибке ключа, изображения и локальная история.
- Пройдены прежние проверки Суперпромпта, вопросов, очереди, ссылок на файлы и CLI-интеграции.
- Пройдены Python-проверки чтения и представления CLI-лимитов.
- Визуально проверены форма подключения, кнопки и семейство иконок в отдельном окне без сети. ICNS загружены через NSImage. Системная строка меню не была доступна инструменту UI-автоматизации; её SF Symbol и template-настройка проверены в исходнике и представлены в визуальном стенде.
- Проверены локальные подписи приложений codesign --verify --deep --strict и структура архивов.

Не проверялись: платные API-запросы, совместимость со всеми сторонними API и реальный пользовательский ключ в Keychain. Формат совместимости — Chat Completions, без выполнения инструментов и без потокового вывода. GitHub Actions добавлен, но удалённый запуск на GitHub ещё не выполнялся.


## 1.1.1

- Перепроверены актуальные установленные исходники и скрипт перезапуска; он открывает правильные `.app` по полному пути, не бинарник.
- Существующий ICNS отдельно отображался, системная иконка bundle была пустой. Штатный iconutil успешно собрал ICNS вне песочницы. Обновлены точное имя ресурса, runtime applicationIconImage и регистрация только Пульта. Finder проверен визуально, иконка присутствует. Dock UI недоступен инструменту (timeout); открытый Пульт не закрывался, поэтому Dock нового процесса не подтверждён.
- Проверены свежие/устаревшие/повреждённые/будущие timestamps, отсутствующие и просроченные окна Claude, некорректные числа и boolean, неизменность времени при перечитывании.
- Проверены скрытие по стабильному пути, переименование записи, сохранение скрытия через повторную инициализацию UserDefaults и восстановление.
- Writer statusLine тестируется на whitelist и отсутствие ложного timestamp при отсутствии данных. Платные модельные запросы не выполнялись. Реальная новая квота Claude из активной интерактивной сессии в ходе этой проверки не получалась.

## 1.2.0

Собраны личный Пульт и публичные Пульт/Лимиты. Сохранена резервная копия перед установкой; процессы пользователя не закрывались. Исходники установленного Пульта сверены с проверенной сборкой; подпись проверена codesign. Лимиты и серверные интеграции не изменялись этой доработкой.

Новые ConversationChecks: наследование/переопределение правил и перезагрузка, стабильные закрепления, сворачивание без удаления текста, ошибки/вопросы/подтверждения остаются видимыми, отдельные Fast-настройки, отсутствие старого продолжения в новом запросе, сохранение/восстановление ветки и очереди, независимые запросы группы, частичный сбой и отмена/поздние события, расчёт смещения якоря прокрутки.

Пройдены регрессии API, Суперпромпта, очереди/вопросов, ссылок и CLI-команд, проверки виджета и Python helpers. Два прежних теста явно выбирают Codex вместо зависимости от сохранённого провайдера пользователя.

Визуальная проверка: Preview с 30 парами сообщений и потоком 600 строк. После ручной прокрутки вверх видимый текст совпадал на двух снимках при продолжающейся генерации; кнопка возвращала к последним строкам. Открыто окно правил. Два падения test-only Preview найдены и устранены: force unwrap тестового UserDefaults и недопустимый scrollTo из layout-уведомления. Исправленный поток прошёл без нового падения. Preview не включён в поставку.

Не выполнялись платные или реальные многоагентные запросы, сетевой Fast, полный тест всех сторонних API. Поддержка Fast зависит от провайдера, а команда показывает запрошенный режим. Группа — только аналитическая, Claude CLI для неё не поддержан. Подробности в FEATURES-1.2.md. GitHub push для этой версии не выполнялся.
