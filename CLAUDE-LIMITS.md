# Данные Claude и скрытые аккаунты — 1.1.1

Claude читается из `~/.claude/limits-cache.json`. Источник — документированный `rate_limits` в statusLine Claude Code. Виджет не имеет самостоятельного поддерживаемого метода запроса квоты подписки. Нажатие «Обновить» перечитывает кеш и не изменяет время его получения. Это не новый запрос к провайдеру.

Свежие данные (до 120 секунд с момента получения из CLI) показываются с точным временем. Устаревшие проценты скрываются, показано «УСТАРЕЛО» и последнее время получения. Просроченное окно сброса не превращается в нулевую загрузку. Повреждённый кеш и отсутствующая квота обозначаются явно.

«Проверить в Claude Code…» открывает штатную интерактивную команду `claude /usage`, без модельного промпта. Она показывает поддерживаемую страницу квоты. Для передачи данных в виджет требуется statusLine; только работающая CLI-сессия с доступными rate_limits может обновлять кеш. В неинтерактивной Claude-ветке Пульта statusLine может не вызываться. Отдельного фонового опроса приватных OAuth endpoint нет, платный запрос для получения квоты не запускается. /usage не гарантирует появление rate_limits в statusLine до ответа модели; если их нет, виджет остаётся честно недоступным.

Настройка для нового пользователя: скопировать `Resources/helpers/statusline-limits.py` в `~/.claude/statusline-limits.py` и добавить в существующий `~/.claude/settings.json`:

```json
{"statusLine":{"type":"command","command":"python3 ~/.claude/statusline-limits.py","refreshInterval":60}}
```

Не перезаписывайте целиком существующий settings.json. Если другая statusLine уже настроена, объедините скрипты вручную. Скрипт сохраняет только whitelist квот с правами 600 и не обновляет timestamp, когда квоты нет. Timestamp означает получение payload от Claude Code, а не независимую сетевую проверку.

Официальные источники:
- https://code.claude.com/docs/en/statusline#rate-limit-usage
- https://code.claude.com/docs/en/costs#using-the-usage-command

## Убрать лишний аккаунт

В Лимитах нажать «Открыть», затем «Скрыть в Лимитах» у записи и подтвердить. Запись исчезнет из виджета и списка после обновления и перезапуска. «Вернуть скрытые записи» возвращает все скрытые записи. Скрытие хранится отдельно в настройках Лимитов по стабильному CODEX_HOME / UUID API, не меняет `~/.codex-accounts.json`, подключения Пульта, авторизацию, Keychain, историю или подписку.

## Иконка

Исходная картинка ICNS открывалась, но NSWorkspace возвращал пустую иконку bundle. ICNS Пульта пересобран штатным iconutil вне песочницы; имя ресурса изменено на PultAppIcon.icns, Info.plist содержит точное имя. При запуске приложение также задаёт applicationIconImage из того же ресурса. Для локального установленного bundle обновлена только его LaunchServices-регистрация, без удаления глобальных кешей. Finder проверен визуально: правильная иконка отображается. Dock не удалось снять через UI-инструмент; открытый Пульт не закрывался, поэтому runtime-исправление появится при следующем безопасном запуске.
