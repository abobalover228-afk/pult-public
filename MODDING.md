# Пульт 2.4 — SDK модов 2

`.pult` — один JSON-файл UTF-8, до 2 МБ. Старый формат 1 поддерживается. Формат 2 добавляет настоящий JavaScript API, встроенные панели, кнопки, хоткеи, события и фоновые расширения.

Готовые примеры: `Examples/native-team.pult` — встроенная командная работа через обычные чаты, доску и WebRTC; `Examples/sdk-playground.pult` — проверка API и прав. Типы: `SDK/pult.d.ts`. Схема для редактора: `SDK/pult-mod.schema.json`. Проверки зависимостей и пересечений идентификаторов дополнительно выполняет сам Пульт.

## Быстрый старт

```json
{
  "format": 2,
  "id": "my-tools",
  "name": "Мои инструменты",
  "version": "1.0.0",
  "author": "Я",
  "permissions": ["chats.read"],
  "commands": [{"name":"open","title":"Открыть инструменты","shortcut":"cmd+alt+m","script":"await pult.call('ui.openPanel',{panel:'tools'});"}],
  "panels": [{"id":"tools","title":"Мои инструменты","placement":"right","html":"<button onclick=\"pult.call('chats.list').then(x=>document.body.append(JSON.stringify(x)))\">Мои чаты</button>"}],
  "sidebar": [{"id":"tools","title":"Инструменты","icon":"wrench.and.screwdriver","panel":"tools"}]
}
```

Установи файл в Настройки → Моды. Кнопка появится в боковой панели; команда `/my-tools/open` и хоткей открывают встроенную панель. Нажатие на личный чат возвращает его в основную область. Панель можно перенести влево, вправо, в центр или отдельный sheet через её заголовок.

## Manifest

`panels`: до 12 панелей с уникальными `id`, `title`, `html`, `placement` (`main`, `left`, `right`, `sheet`). Старая одиночная `panel` считается панелью `main` с размещением `sheet`.

`sidebar`, `toolbar`, `statusbar`: до 20 кнопок в каждой области. У кнопки обязательны `id`, `title` и ровно одно действие `panel` или `command`. `icon` — имя SF Symbol. Ссылки на несуществующие команды и панели отклоняются.

`commands`: до 30 команд. Ровно одно из `prompt`, `shell`, `script`. В `script` доступны `pult` и строка `input`, поддерживается верхнеуровневый `await`. `shortcut` — комбинация `cmd`, `ctrl`, `alt`, `shift` и одной буквы, например `cmd+shift+j`. Системные хоткеи не переназначай.

`background`: JavaScript, который запускается один раз для включённой одобренной версии мода без открытой панели; требует права `background`. Подписки на `app.tick` позволяют работать без таймера фонового WebKit. У фонового кода отдельный контекст; данные с панелями передавай через `storage` или `settings`.

`files`: словарь относительный_путь → UTF-8_содержимое, до 60 файлов. Ресурсы распаковываются в отдельный каталог версии; абсолютные пути, traversal и секретные имена запрещены. Их путь возвращает `app.info.assetsPath`; `dataPath` предназначен для постоянных данных мода. Файлы не выполняются при установке.

`networkDomains`: необязательный список разрешённых доменов; поддерживаются `*.example.com`. Он применяется к CSP панели и к нативным сетевым вызовам, включая редиректы. Без `network` сеть закрыта. Нативный `network.fetch` разрешает HTTPS, а HTTP — только localhost/127.0.0.1/::1. Для старых прямых запросов панели остаётся её CSP.

`settings` и `theme` сохраняют формат 1. Настройки — строки с начальными значениями. Не помещай туда токены.

## JavaScript API

```js
const chats = await pult.call('chats.list');
const unsubscribe = pult.on('chat.finished', ({id, text, failed}) => {
  console.log(id, failed, text);
});
// Когда обработчик больше не нужен:
unsubscribe();
```

Вызов возвращает Promise; ошибки прав и данных отклоняют его. Необработанные Promise-ошибки попадают в журнал мода. API проверяет текущую одобренную версию на каждом вызове; идентификатор другого мода подставить нельзя. Панели не могут вызывать произвольные native-методы.

| Методы | Права | Результат / назначение |
|---|---|---|
| `app.info` | без дополнительных прав | API, версия, id мода, его пути, текущий проект и остаток автоходов |
| `ui.toast`, `ui.openPanel` | свои панели | Уведомление и размещение панели; `panel`, необязательный `placement` |
| `ui.openTeam`, `ui.teamSettings`, `ui.openChat`, `ui.modSettings` | интерфейс | Открыть встроенные области Пульта |
| `log` | своё хранилище | `message`; журнал до 80 записей |
| `settings.get/set` | свои настройки | `key`, `value`; менять можно только объявленные настройки |
| `storage.get/set` | своё хранилище | JSON по `key`; `null` удаляет ключ; до 400 КБ на мод |
| `secrets.get/set` | `secrets` | `key`, `value`; только `.env` этого мода с правами 600, без доступа к глобальным секретам Пульта |
| `chats.list/read` | `chats.read` | Открытые чаты; `read` принимает `id`, `limit` до 200, текст сообщения до 16 тысяч символов |
| `chats.create` | `chats.write` | Независимый чат: `title`, `select`, `provider`, `model`, `cwd` внутри текущего проекта |
| `chats.send` | `chats.write` | `id`, `text` до 200 КБ; обычная задача модели, slash/shell не исполняются |
| `chats.stop/activate` | `chats.write` | Остановить ход или выбрать чат по `id` |
| `chats.append` | `chats.write` | Заметка с явной подписью мода; ответы модели не подделываются |
| `files.list/read` | `files.read` | Относительный `path`, необязательный id чата; до 500 имён или UTF-8-файл до 1 МБ |
| `files.write` | `files.write` | Относительный `path`, `text` до 1 МБ; атомарная запись в проект |
| `git.status/diff` | `files.read` | `status --short` и **статистика** `diff --stat` |
| `team.state` | `team.read` | Прямая комната, доска, локальные агенты, последние 100 сообщений; приглашение и токены не выдаются |
| `team.send/addTask/claim` | `team.write` | Текст; название/detail; либо ids до трёх свободных задач. Назначение подтверждает создатель комнаты, до подтверждения агент не запускается |
| `network.fetch` | `network` | url, method, headers, строковый body до 1 МБ; ответ status/body до 8 МБ |
| `process.start/read/stop` | `process` | Свои именованные процессы: абсолютный executable, arguments[], environment; до восьми одновременно; read возвращает хвост лога до 100 КБ |

Файловый API закрывает выход из проекта через `..` и символьные ссылки, `.env*`, `.git`, `.ssh`, `.aws`, auth.json и распространённые ключевые файлы. Это ограничение относится к файловому API: разрешённые `process` и `shell` запускают программы с правами пользователя и не являются системной песочницей. Перед выдачей этих прав проверь автора и код мода.

`process` позволяет запускать программы без повторного диалога: право явно принимается при установке. Старый `shell` по-прежнему показывает точный код и требует отдельного подтверждения каждого запуска. При отключении мода его процессы завершаются; приложение также останавливает их перед выходом. Если программа сама порождает отделённые процессы, она должна завершать их в обработчике SIGTERM.

## События

`app.tick` (примерно каждые 0,5 с, пока есть включённые моды), `settings.changed` (свои настройки), `process.exited` (свои процессы). Эти события не раскрывают содержимое чатов.

С `chats.read`: `chats.changed` (список/активный чат/статусы), `chat.finished` (`id`, `text`, `failed`, `teamTask`), `chat.question`, `chat.approval`. События вопросов и разрешений уведомляют о необходимости ответа; автоматически принимать их API не позволяет. Существующие средства автоодобрения пользователя остаются настройками самого чата.

`chat.finished` команды содержит `teamTask`, остальные личные чаты — пустую строку. Не публикуй личные сообщения в общую комнату без осознанной команды пользователя. Встроенный native-team передаёт только результаты назначенных общих задач.

## Жизненный цикл и лимиты

При выключении отзывается мост API, останавливаются фоновые обработчики и собственные процессы, закрываются панели. Заменённая версия не наследует старые активные JS-контексты. Ручная правка установленного `.pult` меняет fingerprint: до переустановки код и API блокируются. Кнопка «Перечитать файлы модов» обнаруживает такие изменения, но не одобряет их молча.

На мод — 80 вызовов API в секунду и 20 отправок модели/назначений задач за запуск Пульта. Ещё 20 выдаёт человек в настройках мода; публичного API сброса этого лимита нет. Назначения native-team и прямые автоответы командных агентов имеют отдельные ограничения: у каждого агента до восьми автоматических продолжений, очередь до 16 сообщений. Дополнительные продолжения разрешаются кнопкой в общем чате. Лимиты ограничивают автоматику приложения, но не являются денежным бюджетом провайдера.

События не являются долговременной очередью: сохраняй своё состояние, не запускай повторно уже начатые задачи. Коллективная доска атомарно назначает задачу одному владельцу; native-team использует этот механизм и отдельные Git worktree.

## Встроенная «Одна команда»

Кнопка в боковой панели открывает главный экран внутри Пульта, ⌘⇧J — тот же экран. Настрой обычную комнату и GitHub, передай приглашение напарнику. Оба участника должны использовать 2.4 для общения встроенных агентов.

Добавь общую цель планировщику, включи «Брать свободные задачи». Агенты запускаются в обычных чатах с их моделями и аккаунтами. Они могут отправлять адресные блоки `pult-agent` другим назначенным задачам; сообщения видны в общем чате, получатель отвечает после своего текущего хода. Занятый/остановленный агент и вопросы человека не обходятся. «Не брать новые» останавливает только автоназначение, активные ходы останавливаются кнопкой в их чатах.

Вопросы коллег не синхронизируют файлы. Код каждой задачи остаётся в её ветке и папке. Просмотр diff, push/PR и финальное объединение остаются явно подтверждаемыми действиями. Автоматического переноса непроверенного кода между ПК этот встроенный мод не делает.

# Моды .pult — формат 1

`.pult` — один UTF-8 JSON-файл, без архива, установки пакетов и скрытых файлов.
Установка: Настройки → Моды → Установить из файла, либо открытие `.pult` в Пульте.
Перед установкой показываются автор, версия и права. Мод не запускает код при установке.
Отключение убирает его команды и тему. Настройки и выбранная тема сохраняются после перезапуска.

Начни с [Examples/starter.pult](Examples/starter.pult). Обязательные поля:

```json
{
  "format": 1,
  "id": "my-mod",
  "name": "Мой мод",
  "version": "1.0.0",
  "author": "Имя автора",
  "permissions": [],
  "settings": {"language": "Русский"},
  "commands": [
    {"name": "explain", "title": "Объяснить", "prompt": "Объясни на {{setting:language}}: {{input}}"}
  ],
  "theme": {"accent": "#B99AFF", "background": "#171220"},
  "panel": {"title": "Моя панель", "html": "<h1>Привет!</h1>"}
}
```

`id` и имена команд: латинская буква, затем до 47 букв, цифр или дефисов.
Команда вызывается `/my-mod/explain текст`; `{{input}}` заменяется аргументом.
`settings` — текстовые параметры с начальными значениями: редактируются в настройках мода,
сохраняются отдельно от файла, доступны промпту как `{{setting:имя}}`, панели как
`window.pultSettings`, shell-коду в JSON-переменной `PULT_MOD_SETTINGS`.
Не храни здесь токены и ключи: секреты должны лежать в `.env`.

`theme`, `panel`, `settings`, `description` необязательны. Цвета — `#RRGGBB`.
Максимум 2 МБ, 30 команд и 30 параметров. Команда содержит ровно одно поле:
`prompt` (задача агенту) или `shell` (код zsh).

Для shell обязательно `"permissions": ["shell"]`. Каждый запуск требует отдельного
подтверждения с показом кода, аргумента и рабочей папки; автоподтверждения агента
на моды не распространяются. Код выполняется с правами пользователя в папке
выбранного чата. Аргумент передаётся как `$1`, без подстановки в код:

```json
{"name": "inspect", "title": "Показать ветку", "shell": "git status --short; printf '%s\\n' \"$1\""}
```

Запуск ограничен 60 секундами, в ленту попадает хвост вывода до 100 КБ.
Полноценной системной песочницы у shell нет: устанавливай моды от доверенных авторов.

Панель открывается в WebKit без доступа к чатам, файлам, токенам и нативным API.
Разрешены встроенные CSS и JavaScript, `data:`-изображения. Внешняя сеть
заблокирована; `"network"` в permissions разрешает HTTP(S)/WebSocket-запросы и картинки.
Переходы по ссылкам, iframe и формы заблокированы. Хранилище браузера временное;
для постоянных параметров используй `settings`.

После обновления мода с тем же id сохранённые параметры остаются.
В первой версии нет автоматического обновления модов и реестра: передавай файл `.pult`.
