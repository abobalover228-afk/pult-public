# Первая загрузка и дальнейшие обновления

Распакуй весь архив в отдельную папку, например `~/Documents/pult-github`.
Не распаковывай внутрь другого Git-репозитория. Открой Terminal в распакованной папке `pult`.

## Первая загрузка

Создай на GitHub пустой репозиторий (без автоматически добавленных README и лицензии).
В командах ниже замени YOUR_NAME своим логином.

```sh
git init -b main
git add .
git status
git commit -m "Initial Pult and Limits release"
git remote add origin https://github.com/YOUR_NAME/pult.git
git push -u origin main
```

Если Git просит имя и почту, настрой их для этого репозитория:

```sh
git config user.name "Твоё имя"
git config user.email "Твоя почта GitHub или GitHub noreply"
```

GitHub при HTTPS требует свой способ авторизации (например GitHub CLI или credential manager), обычный пароль аккаунта не подходит. При установленном GitHub CLI можно предварительно выполнить `gh auth login`.

## Как обновлять

Это отдельная публичная копия исходников. Меняй файлы именно в этой папке; изменения другого установленного Пульта сами сюда не попадают.

Перед работой, когда нет незакоммиченных изменений:

```sh
git pull --ff-only
```

После правок:

```sh
bash check.sh
bash build.sh
git add .
git diff --cached --stat
git commit -m "Describe your changes"
git push
```

Исходники, ресурсы, проверки, инструкции и workflow попадут в Git. Готовые приложения, ZIP, кэш сборки и личные настройки игнорируются. После каждого push GitHub Actions проверяет и собирает приложения; архив появится в Actions → запуск → Artifacts. Срок хранения артефакта ограничивается настройками GitHub. Для постоянной раздачи создай GitHub Release и приложи `Pult-macOS.zip` из локальной сборки.

## Как обновить установленное приложение

Закрой Пульт и Лимиты, собери новую версию или скачай новый архив, замени обе `.app` рядом друг с другом. Их настройки, история CLI и авторизации хранятся отдельно от приложений.

Папка `Apps` в этом комплекте содержит уже готовую локальную сборку для Apple Silicon. Её можно использовать сразу; она не отслеживается Git. Для новой сборки нужны Xcode Command Line Tools. Python 3.10+ и CLI требуются согласно README.
