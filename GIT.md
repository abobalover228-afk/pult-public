# Скачать исходники и обновить Пульт

Репозиторий: [abobalover228-afk/pult-public](https://github.com/abobalover228-afk/pult-public).

## Что скачивать

- **Исходники** — код, ресурсы, инструкции и проверки. Code → Download ZIP и `git clone` скачивают исходники. Готовых `.app` и папки `Apps` в Git нет.
- **Actions Artifacts** — результат успешной автоматической сборки. Открой [Actions](https://github.com/abobalover228-afk/pult-public/actions), выбери успешный запуск и скачай `Pult-macOS` из Artifacts. Для скачивания может потребоваться вход в GitHub; срок хранения ограничен.
- **Releases** — версии, отдельно опубликованные автором. В [Releases](https://github.com/abobalover228-afk/pult-public/releases) скачай `Pult-macOS.zip` из Assets, если он приложен. Успешная сборка сама по себе не создаёт Release.

Распакуй готовую сборку. У Artifact может быть вложенный `Pult-macOS.zip`: распакуй и его. Дальнейший запуск описан в [README.md](README.md).

## Скачать исходники

Открой Terminal в удобной папке вне другого Git-репозитория:

```sh
git clone https://github.com/abobalover228-afk/pult-public.git
cd pult-public
```

Для локальной сборки нужны macOS и Xcode Command Line Tools. Если инструменты ещё не установлены, выполни `xcode-select --install`, затем:

```sh
bash check.sh
bash build.sh
```

Результат: `dist/Пульт.app`, `dist/Лимиты.app` и `Pult-macOS.zip`. Требования к Python и CLI указаны в [README.md](README.md).

## Авторизация для отправки изменений

Для push нужны права записи в репозиторий. Если их нет, создай fork на GitHub, отправь изменения туда и открой Pull Request.

Если Git просит имя и почту, настрой их для этого репозитория:

```sh
git config user.name "Твоё имя"
git config user.email "Твоя почта GitHub или GitHub noreply"
```

GitHub при HTTPS требует свой способ авторизации (например GitHub CLI или credential manager), обычный пароль аккаунта не подходит. При установленном GitHub CLI можно предварительно выполнить `gh auth login`.

## Как обновлять

Это отдельная публичная копия исходников. Меняй файлы именно в этой папке; изменения другого установленного Пульта сами сюда не попадают.

Перед работой, когда нет незакоммиченных изменений:

```sh
git pull --ff-only
```

После правок:

```sh
bash check.sh
bash build.sh
git add .
git diff --cached --stat
git diff --cached
git commit -m "Describe your changes"
git push
```

Исходники, ресурсы, проверки, инструкции и workflow попадут в Git. Готовые приложения, ZIP, кэш сборки и личные настройки игнорируются. Workflow настроен на проверки и сборку после push и Pull Request; архив появится в Actions → запуск → Artifacts после успешного выполнения. Срок хранения артефакта ограничивается настройками GitHub. Для постоянной раздачи создай GitHub Release и приложи `Pult-macOS.zip` из локальной сборки.

## Как обновить установленное приложение

Закрой Пульт и Лимиты, собери новую версию или скачай новый архив, замени обе `.app` рядом друг с другом. Их настройки, история CLI и авторизации хранятся отдельно от приложений.

Готовые приложения скачиваются отдельно из Releases или Actions Artifacts, когда там доступна сборка. Для новой локальной сборки нужны Xcode Command Line Tools. Python 3.10+ и CLI требуются согласно README.

## API и личные данные

API-ключи в репозиторий не копируются: они находятся в Keychain. Реальные `connections.json`, история, файлы авторизации и связки ключей не входят в этот комплект. Настройки API задаются каждым пользователем в Пульте. Не переносите личный каталог Application Support в исходники.

Текущая версия: 1.2.0. Новые функции описаны в FEATURES-1.2.md. Исправления Claude/иконки и скрытие записей описаны в CLAUDE-LIMITS.md. Актуальные исходники находятся в `Sources`; приложения после локальной сборки — в `dist`. Не заменяйте публичный каталог целиком личным `~/Documents/pult`: у личного Пульта есть свои интеграции, которые исключены из публичной версии.
