Пульт 2.4 — встроенные моды и SDK 2 (macOS 14+, Apple Silicon).

- Панели модов открываются прямо в основном окне, слева, справа или отдельным sheet. Кнопки можно добавлять в боковую и верхнюю панели, нижнюю строку, меню и хоткеи.
- Настоящий JavaScript API: события и управление чатами, свои настройки/JSON-хранилище/.env, файловый API проекта, HTTP-запросы, ресурсы и собственные процессы. Права проверяются при каждом вызове. Выключение мода останавливает его фоновые обработчики и процессы.
- Встроенная «Одна команда» использует обычные чаты, общую доску и прямую комнату Пульта. Планировщик раскладывает цель на карточки, мод берёт свободные задачи; у каждой своя папка и Git-ветка. Включить автоназначение нужно самостоятельно.
- Агенты назначенных задач могут обращаться друг к другу: сообщения видны в общем чате, занятый агент получает их после текущего хода. Есть выключатель, очереди, проверка автора и предел восьми автоответов на агента.
- Старые .pult работают. В комплекте документация, TypeScript-типы, JSON Schema и живой SDK-пример с демонстрацией отказа недостающих прав.

Обоим участникам обновиться: Настройки → Обновления → Проверить сейчас → Обновить. Перед перезапуском завершите активные ходы и выйдите из прямой комнаты. «Одна команда» появится в боковой панели; ⌘⇧J открывает её экран. Обычный чат выбирается нажатием на него в списке.

Комната и GitHub настраиваются как раньше. Код задач остаётся в отдельных ветках: push/PR и объединение выполняются после проверки пользователем. Автоматической передачи непроверенных файлов между ПК нет. Права process/shell позволяют запускать программы с правами пользователя; выдавайте их доверенным модам. Общие вопросы и разрешения не принимаются через API автоматически.

Сборка ad-hoc, без нотариального заверения Apple. Прямой WebRTC без TURN сохраняет ограничения некоторых NAT/корпоративных сетей. Прямой обмен, очереди и защита от повторов проверены на локальных клиентах; отдельная проверка между двумя физическими ПК ещё нужна.
