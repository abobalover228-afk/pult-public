# Проверка порта, 16 ноября 2026

## Подтверждено локально на macOS

- 52 Playwright-теста проходят. Основной интерфейс использует подменённый Tauri IPC; это не замена нативной проверке провайдеров.
- 33 Rust-теста проходят: локальный HTTP round trip, права модов и процессы, Git worktrees, сохранение диалогов и доски, ограничение чтения изображений и другие проверки.
- Реальная пара Chromium WebRTC передаёт фрагментированный пакет 50 КБ через исходный Python rendezvous. Подмена адреса ICE на loopback находится только в тесте для одной машины. Это не проверка внешнего NAT или совместимости Mac/Windows.
- `cargo check --target x86_64-pc-windows-msvc` проходит с локальным Zig resource compiler. Это проверка компиляции, не сборка установщика и не запуск Windows.
- Нативный Tauri запуск проверял загрузку main/limits через IPC. MCP stdio проверял initialize, tools/list и запрет скриншота до включения.
- В настоящем приложении через UI открыт каталог установленного Codex: 8 моделей. `/version` выполнил Codex CLI 0.169.0, код выхода 0.
- Настоящий Claude Code ответил на control initialize без пользовательского запроса.

## Инцидент ручной проверки

Первый нативный пробный ввод `/version` оказался одиночным `/` и был отправлен как обычный запрос; сработало переключение после лимита. Ход остановлен. Расход не измерялся. После этого добавлен тест и защита: пустые и неизвестные slash-команды не отправляются провайдеру. Повторная проверка `/version` выполнялась только после сверки вставленного текста.

## Ещё не подтверждено

- Windows NSIS: сборка, установка, запуск, трей, автозапуск, файловые диалоги, пути с кириллицей и пробелами.
- На Windows: микрофон и System.Speech, управление экраном и вводом, системные уведомления установленного приложения.
- Полный живой сценарий Codex/Claude: авторизация, ответы, разрешения, прерывание, восстановление и перенос аккаунтов. Автотесты не отправляют платные ходы модели.
- Внешняя Mac/Windows-комната, нестабильная сеть и реальная публикация GitHub PR. В разработке push/PR не выполнялись.
- Реальные сообщения Telegram, SSH-выкладка бота, VLESS-подключение и установка обновления. В разработке они не запускались.

Готовность полного релиза не подтверждена. Следующий необходимый этап — Windows workflow и проверка установленного приложения на Windows.
