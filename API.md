# Пульт и Лимиты: API-подключения и значки

В меню аккаунта Пульта выбери «Добавить / изменить API…». Укажи название, ключ, base URL (например `https://api.openai.com/v1`) и точный идентификатор модели провайдера. Нажми «Сохранить», затем «Выбрать» или выбери подключение в меню аккаунтов. Можно изменить запись, оставить ключ пустым для сохранения старого или удалить запись вместе с ключом. Codex и Claude CLI остаются доступны рядом.

Сохранение и выбор не отправляют API-запросов. Запросы начинаются при отправке сообщения или запуске Суперпромпта и могут тарифицироваться провайдером. Автоматических тестовых запросов и повторов после ошибки нет.

Ключ хранится как Generic Password в macOS Keychain (service `local.pult.api-connections`, account — UUID подключения), доступен только на разблокированном устройстве и не синхронизируется. В JSON лежат только UUID, название, base URL и модель. Ключ не передаётся через аргументы командной строки, не включается в историю, Git и архивы. При обновлении локально подписанного приложения Keychain может попросить пользователя снова разрешить доступ. Внешние API-ошибки не выводятся сырым текстом, чтобы не раскрыть секреты. Перенаправления HTTP запрещены; URL принимает HTTPS, HTTP — только localhost. Ключ отправляется только выбранному провайдеру в Authorization.

Поддерживается `/chat/completions`, текстовый ответ целиком (без потокового вывода), изображения через image_url, счётчики токенов при их наличии. Для изображений нужна поддержка vision на стороне модели. Локальная история, очередь, отмена и Суперпромпт работают и с API. При переключении на API сообщения и изображения текущего диалога передаются выбранному провайдеру при следующем запросе. Вывод CLI-команд в обычный API-чат автоматически не переносится; Суперпромпт отдельно получает всю доступную историю UI. Модель Суперпромпта для API — модель выбранного подключения.

CLI-специфичны: выполнение shell-команд, MCP и плагины, агентные инструменты, запросы прав и карточки вопросов инструментов, квоты подписки и CLI-команды. Через API инструменты не исполняются; неподдерживаемые команды показывают объяснение. Автоматические уточнения Суперпромпта реализованы отдельно и работают через обе ветки. API-квоты не угадываются, показано «неизвестно»; счётчики токенов — не денежный баланс.

Общие метаданные подключений и локальная API-история находятся в `~/Library/Application Support/PultConnections`. История содержит тексты и пути вложений, хранится с правами 600 в папке 700. Метаданные видны обоим приложениям; Лимиты не читают ключи. Удаление подключения не удаляет историю. Выбранное подключение сохраняется в настройках приложения.

Значок шкалы в Пульте открывает приложение Лимиты. В строке меню macOS тот же символ заменяет надпись; левый и правый клик сохраняют прежнее поведение. У иконок приложений общие графитовый фон, светлые линии и медный акцент; окно терминала обозначает Пульт, шкала — Лимиты. Генератор ресурсов находится в Design/GenerateIcons.swift.

Офлайн-проверки используют Keychain-заглушку и URLProtocol, не настоящие ключи и не внешний API. Покрыты CRUD, секреты вне JSON/тела запроса, редактирование без замены ключа, ошибки хранилища, некорректные URL, блокировка редиректов, HTTP-ошибки, реальный маршрут отправки с транспортом-заглушкой, очередь, история и отмена. Реальный платный запрос не выполнялся. Системную строку меню инструмент UI-автоматизации не смог снять; иконка в коде проверена как template SF Symbol и визуально в окне стенда.

Протокол Chat Completions: https://developers.openai.com/api/reference/resources/chat .
