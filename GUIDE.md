# Гайд по Пульту 2.0

## Первый запуск

Пульт — окно для установленных Codex CLI и Claude Code, а также API-чата. Для CLI сначала установи помощника и войди в аккаунт через его официальный Terminal-клиент. В меню аккаунта выбери помощника. В настройках → Работа выбери папку проекта. Начни с задачи «Изучи проект и объясни, как его запустить». API подключается через меню аккаунта → Добавить / изменить API; возможности инструментов зависят от подключения.

## Несколько чатов одновременно

⌘N создаёт отдельный чат: у него собственный процесс, очередь, модель и рабочая папка. Пока один чат работает, переключись в другой и отправь задачу. ⌘1…9 переключают открытые чаты, ⌘K ищет чат или действие. Черновик остаётся в своём чате. Следи за статусами «Работает», «Ждёт твоего ответа», «Ждёт разрешения», «Ошибка» и «Готово — не прочитано». Два агента, меняющие одни и те же файлы, могут конфликтовать: для независимых правок используй отдельные папки или git worktree.

## Модели, команды и очередь

Кнопка с названием модели возле поля ввода открывает выбор модели и глубины размышлений. Каталог Codex загружается из CLI: доступность зависит от аккаунта и версии. Начни ввод с /, чтобы увидеть команды и подсказки; /help покажет справку. Enter отправляет, ⌥Enter добавляет строку. Во время работы новые сообщения можно поставить в очередь. Esc останавливает ответ. Команда ! запускает локальную команду проекта — проверяй её содержимое.

## Вопросы и разрешения

На карточке вопроса выбери вариант или введи свой ответ, затем отправь его. Карточка разрешения позволяет принять или отклонить действие. В настройках → Работа выбери песочницу и режим подтверждения. По умолчанию автоподтверждение выключено. Если включить «Подтверждать действия за меня», Пульт будет принимать и дополнительные разрешения автоматически. Вопросы Codex вне режима планирования зависят от экспериментальной возможности установленного CLI.

## Telegram с телефона

1. Создай собственного бота через @BotFather в Telegram и получи токен.
2. Открой настройки Пульта → Telegram, вставь токен и нажми «Подключить».
3. Открой своего бота и отправь код привязки, показанный Пультом. После привязки бот принимает сообщения только от владельца.
4. /chats — список чатов и выбор, /new задача — новый чат, /status — состояние, /last — последний ответ, /stop — остановить, /help — справка. Обычный текст отправляется в выбранный чат; вопросы и разрешения приходят с кнопками.
Mac должен быть включён, а Пульт запущен и иметь доступ к сети. Не запускай второй экземпляр с тем же токеном. Токен хранится в ~/Library/Application Support/PultPublic/.env с правами 0600. Не публикуй его.

## Голос

Нажми микрофон или ⇧⌘M и разреши микрофон и распознавание речи в macOS. Диктовка заполняет поле задачи. В настройках → Голос выбери язык, озвучку ответов и режим «без рук»: пауза в речи отправляет задачу, после озвучки ответа микрофон включается снова. В этом режиме речь может отправиться автоматически, поэтому начинай с простых задач. Если доступа нет, проверь Системные настройки → Конфиденциальность и безопасность → Микрофон / Распознавание речи.

## Обновления с GitHub

Готовую сборку можно скачать из Releases репозитория abobalover228-afk/pult-public. Встроенная сборка обновлений требует локального git clone, Xcode Command Line Tools и доступного GitHub. Путь к исходникам хранится в сборке; для скачанного приложения выбери папку клона в настройках → Обновления. Привяжи https://github.com/abobalover228-afk/pult-public.git, проверь обновления и установи. Автоустановка изначально выключена; её можно включить. Она ждёт завершения всех чатов, подтягивает изменения через fast-forward, собирает и перезапускает приложение. При локальных конфликтах git или ошибке сборки обновление останавливается. Перед ручной установкой закончи активные задачи.

## Если что-то пошло не так

Codex или Claude не найден: проверь установку и вход через Terminal; перезапусти Пульт. Ошибка процесса: переподключи чат через ⌘K. Нет модели: обнови CLI и проверь аккаунт. Нет Telegram: проверь токен, привязку, сеть и отсутствие другого запущенного бота с этим токеном. Голос не работает: проверь разрешения macOS. Не появились обновления: проверь путь исходников, origin и доступ к GitHub. Лимиты.app остаётся отдельным приложением: положи его рядом с Пультом. Голос и Telegram требуют отдельной проверки на твоём устройстве после подключения.
