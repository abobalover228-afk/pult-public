Пульт 2.3 для macOS 14+ (Apple Silicon).

- Моддинг .pult: темы, команды, свои HTML-панели и постоянные параметры. Установка из файла или двойным нажатием. Shell-код — только после отдельного подтверждения каждого запуска.
- Сохранение настроек ленты, разрешений Claude, песочницы, переключения аккаунтов и параметров модов. Разворот вывода команд больше не сбрасывается после ответа.
- Автоматические папки для командной работы: Пульт сам скачивает проект и создаёт отдельную папку и Git-ветку для задачи.
- Неактивная кнопка «Взять в работу» показывает точную причину. Чат команды, задачи и результаты общие; переписка с агентом остаётся личной.

Обновиться: Настройки → Обновления → Проверить сейчас → Обновить. Обновиться нужно обоим участникам. Перед обновлением заверши работу агентов и выйди из комнаты. Альтернатива: распакуй архив и перенеси приложения в ~/Applications.

Создатель комнаты должен подключить GitHub-репозиторий. Для приватных репозиториев нужен авторизованный Git на каждом компьютере; токен PR в Пульте используется для GitHub API. Нужен установленный CLI с авторизацией либо API-подключение. Подпись ad-hoc, без нотариального заверения Apple. TURN отсутствует: некоторые сети могут не соединиться.

Формат модов: MODDING.md и Examples/starter.pult в репозитории; пример также можно сохранить из настроек модов.
