# Сервер комнат Пульта

Нужен, чтобы два Пульта нашли друг друга. Без него режим «Вместе» не работает.

Что делает сервер:

- **Знакомит компьютеры.** Передаёт зашифрованные параметры подключения, после чего Пульты соединяются напрямую.
- **Пересылает содержимое, если напрямую не получилось** (включается владельцем сервера). Сообщения и задачи шифруются ключом комнаты. Ключ есть только в приглашении и на сервер не попадает, поэтому сервер видит лишь зашифрованные блоки.

Сервер ничего не хранит на диске. Комната живёт в памяти и исчезает через час без активности или при перезапуске.

## Что нужно

- Linux с systemd и Python 3.9 или новее. Сторонние пакеты не нужны.
- HTTPS-адрес: домен и прокси перед сервером (например, Caddy). Пульт не принимает адреса без HTTPS.

## Установка

Скопируй папку `signaling` на сервер и выполни:

```sh
sudo sh install.sh
```

Скрипт ставит сервер в `/opt/pult-rendezvous`, запускает его службой на `127.0.0.1:8787` и печатает адрес и токен создания комнат. Если на сервере уже работает Caddy, путь `/pult-link` подключается к нему сам.

| Команда | Что меняется |
|---|---|
| `sudo sh install.sh` | С пересылкой, комнаты создаёт только владелец токена |
| `sudo sh install.sh --no-relay` | Без пересылки: содержимое идёт только напрямую |
| `sudo sh install.sh --open` | Комнаты создаёт любой, кто знает адрес |

Повторный запуск обновляет файлы и сохраняет прежний токен.

## Настройка в Пульте

Открой **Вместе → ⋯ → Проект, GitHub и имя → Сервер комнат**:

1. Впиши адрес, например `https://твой.домен/pult-link`.
2. Нажми **Проверить**: Пульт покажет, отвечает ли сервер и включена ли пересылка.
3. Впиши токен создания комнат и нажми **Сохранить**.

Кенту ничего настраивать не нужно: адрес сервера зашит в приглашение.

## Обслуживание

```sh
systemctl status pult-rendezvous        # состояние
journalctl -u pult-rendezvous -n 50     # журнал
cat /opt/pult-rendezvous/.env           # адрес порта, токен, пересылка
```

Удаление:

```sh
systemctl disable --now pult-rendezvous pult-rendezvous-route.timer
rm -rf /opt/pult-rendezvous /etc/systemd/system/pult-rendezvous*
systemctl daemon-reload
```

## Ограничения

- До 32 комнат и до 8 участников в комнате.
- Пересылка: блок до 48 КБ, до 1200 блоков в минуту на участника.
- Служба ограничена 128 МБ памяти и 20% одного ядра.
