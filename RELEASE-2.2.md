Пульт 2.2 для macOS 14+ (Apple Silicon).

- Общий проект: прямой чат и общая доска задач через WebRTC.
- Защита от двойного назначения, отдельный чат и Git worktree на задачу.
- Просмотр изменений, публикация ветки и создание GitHub PR после подтверждения.
- Пятичасовой и недельный лимиты аккаунтов.
- Обновления через GitHub Releases: SHA-256, проверка подписи, резервная копия.

Распакуй Pult-macOS.zip и перенеси Пульт.app и Лимиты.app в ~/Applications. Подпись ad-hoc, без нотариального заверения Apple. CLI с авторизацией или API настраиваются отдельно. Создание комнаты требует разрешения владельца службы знакомства; участникам достаточно приглашения. TURN отсутствует, некоторые сети могут не соединиться.

Проверены сборка, локальная служба комнат, назначения задач, Git worktrees, фильтрация событий и обновление с резервной копией. GitHub PR проверен mock API; сквозная работа между двумя разными ПК не проверена.
